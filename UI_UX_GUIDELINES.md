# Finsarth AI UI/UX Guidelines
## Purpose
Define the visual and experience standards for Finsarth AI.
All UI decisions must follow this document.
---
# Product Personality
Finsarth AI should feel:
- Modern
- Intelligent
- Clean
- Fast
- Trustworthy
- Premium
It should NOT feel like:
- Traditional banking software
- Excel dashboards
- Government portals
- Legacy finance applications
---
# Inspiration
Primary Inspirations:
 
- Ramp
- Mercury
- Revolut
- Stripe Dashboard
- Vercel
- Linear
- Notion
---
# Design Principles
## Simplicity First
Users should understand the interface within 60 seconds.
Avoid clutter.
---
## AI First
The product should highlight insights and actions rather than raw data.
Bad:
Food: ₹10,000
Good:
You spent 18% more on dining this month.
---
## Action Oriented
The dashboard must tell users:
- What happened
- Why it happens
- What action to take
---
## Mobile First
Every screen should work well on mobile before desktop.
---
# Navigation Structure
Phase 1 Navigation
- Home
- Transactions
- Insights
- Accounts
- Settings
Avoid large enterprise-style sidebars.
---
# Landing Page
Goal:
Explain value in less than 30 seconds.
Sections:
 
- Hero
- Features
- How It Works
- AI Insights Preview
- Call to Action
---
# Authentication Pages
Required Pages:
- Login
- Signup
Requirements:
- Minimal fields
- Clear actions
- Fast onboarding
---
# Dashboard Design:
Primary Focus:
Financial understanding.
Dashboard must show:
- Total Spending
- Spending Trends
- Top Categories
- AI Recommendations
Avoid information overload.
---
# Transaction Page
Users should be able to:
- Search
- Filter
- Categorize
- Review transactions
Design should resemble modern SaaS applications.
---
# AI Insights Page
This is the hero feature,
Focus on:
- Spending analysis
- Savings opportunities
- Behavioral trends
AI recommendations should be prominent.
---
# Cards
Use cards instead of large tables whenever possible.
Examples:
- Monthly Spending
- Top Category
- Savings Opportunity
---
# Charts
Allowed:
- Donut Charts
- Bar Charts
- Trend Charts
Avoid:
- Complex financial charts
- Overloaded visualizations
---
# Color Palette
Primary:
#0F172A
Accent:
#06B6D4
Success:
#22C55E
Warning:
#F59E0B
Background:
#F8FAFC
---
# Typography
Simple and readable.
Prefer:
- Inter
- Geist
Avoid decorative fonts.
---
# Animations
Use subtle animations only.
Examples:
- Smooth page transitions
- Hover effects
- Counter animations
Avoid excessive motion.
---
# Accessibility 

All pages must support:
- Keyboard navigation
- Good color contrast
- Mobile responsiveness
---
# Golden Rule
Every screen should answer:
1. What happened?
2. Why did it happen?
3. What should the user do next?
If a screen cannot answer these questions, redesign it.
