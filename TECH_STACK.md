# Finsarth AI Technology Stack
## Purpose
 This document defines the technologies used in Finsarth AI and explains why they were chosen.
---
# Frontend
## Next.js
Purpose:
Build the user interface and application pages.
Why Chosen:
- Modern SaaS standard
- Fast development
- Excellent AI support
- Easy deployment
Responsibilities:
- Landing Page
- Login
- Signup
- Dashboard
- Transactions Page
- Insights Page
---
# Styling
## Tailwind CSS
Purpose:
Application styling.
Why Chosen:
- Fast UI development
- Modern SaaS appearance
- Consistent design system
Responsibilities:
- Layout
- Colors
- Typography
- Responsive Design
---
# UI Components
## shadcn/ui
Purpose:
Reusable interface components.
Why Chosen:
- Professional SaaS look
- Highly customizable
- Popular modern stack
Responsibilities:
- Buttons
- Forms
- Cards
- Tables
- Dialogs
---
# Backend
## Supabase
Purpose:
Backend services.
Why Chosen:
- Authentication includes
- Database included
- Storage included
- Easy maintenance
Responsibilities:
- Authentication
- Database
- File Storage
---
# Database

Purpose:

- Reliable

- Users

- Transactions
- Categories
- Insights

# Guiding Principle
Keep the stack simple.
Choose technologies that:
- Reduce development time
- Reduce maintenance effort
- User feel smooth to use and ui/ux saas saas based modern
